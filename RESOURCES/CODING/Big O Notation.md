
# Data Structures
A container to store and organise a specific type of data.
eg. Stack, Queues, Arrays etc.

Here the requirement is to store data in some organised manner, so that we can access it efficiently.

# Algorithms
Step by Step instructions to achieve a particular goal using data and manipulating it if needed.

## How to check the correctness of an algorithm?
- It is able to give the correct answer for all test cases (scenarios).
- For a correct algorithm we then check efficiency.
	- Space Complexity
	- Time Complexity

### Space Complexity
Here it refers to the memory being utilised. And this is RAM, cause thats where programmes are run.

### Time Complexity
Here it refers to the time taken. We have three cases
- Best Case
- Average Case
- Worst Case
Since we don't know the input, we usually consider worst case as reference.

### Big O Notation
Here it refers to the time/memory taken as a relation function of the input provided. Here we consider O(1), to be constant and referring to a unit of work. In case of Time Complexity it can be taken as time taken to complete one cycle operation.

#### Rules for Big O Notation:
- Consider only the largest polynomial (degree of the polynomial). 
- Ignore constants (be it coefficient or another constant in the expression)
